# ECE Nexus

Create a modern, professional and fully responsive ECE Department Digital Hub website using React.js with JavaScript.

IMPORTANT TECH REQUIREMENTS

Use React.js

Use JavaScript only

Do NOT use TypeScript

Use Vite

Use Tailwind CSS

Use Lucide React for icons

Frontend only

Do NOT create backend

Do NOT use Supabase

Do NOT create authentication

Do NOT create a database

Use static/mock data

Keep components reusable and well organized

WEBSITE GOAL

Create a premium digital platform for an Electronics and Communication Engineering (ECE) college department.

The website should help students and visitors explore:

Department information

Faculty

Laboratories

Student projects

Learning resources

Events

Announcements

Placements

Achievements

Contact information

The website should look like a real professional college department website, not a basic student template.
